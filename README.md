# CEREF Africa Consulting — première version

Ouvrir index.html dans un navigateur. Le site utilise HTML, CSS et JavaScript, sans installation ni compilation. Les polices Google nécessitent Internet ; une police système prend le relais hors ligne.

Fichiers : index.html (contenu), style.css (apparence et mobile), script.js (menu, filtres, galerie, préparation d’e-mail), assets/ (vos six supports originaux).

Le formulaire ouvre l’application e-mail du visiteur. Il ne stocke aucune donnée et ne transmet pas automatiquement les demandes. Les langues disponibles, prix et horaires n’ont pas été inventés : ils pourront être ajoutés après confirmation.

Pour la mise en ligne, déposer tout le contenu de ce dossier sur un hébergement statique. Cette version n’a pas été déployée.

## Suivi du projet avec Git

Le dépôt contient les sources HTML, CSS et JavaScript, les supports fournis et les trois illustrations SVG originales. Les styles restent dans `style.css`.

La branche principale est `main`. Pour consulter les modifications : `git status`. Pour enregistrer une étape : `git add .` puis `git commit -m "Description des modifications"`.

Ce dépôt est local ; aucun hébergement distant n’est configuré.
